## What this is

Meadow is a design system on top of shadcn-svelte and a showcase site for it: a landing page (`/`), a components catalog in seven groups (`/components`, `/components/<group>`), a styles page for the tokens (`/styles`) and a dashboard demo composed from the components (`/dashboard`, its own layout outside the `(site)` group). Every shadcn-svelte component is installed in `src/lib/components/ui` and restyled; `typography` is ours (shadcn-svelte ships none). The site shell (header, footer, theme controls, wordmark) lives in `src/lib/components/site`; the catalog scaffolding (`PageIntro`, `Section`, `Demo`, `CatalogPage`) in `src/lib/components/showcase`; larger demos in `src/lib/components/demos/<group>` (the forms, the sortable data table, the chart data in `demos/data/hollin-data.ts`); landing, styles and dashboard pieces in `src/lib/components/{landing,styles,dashboard}`; the group registry in `src/lib/showcase/groups.ts`; the palette list in `src/lib/theme/palettes.ts`. A `.claude/launch.json` entry named `dev` starts the dev server for the browser preview.

## Design

**Style in one line:** warm, modern, editorial. Paper-coloured page, big plain sans-serif headlines, two soft colour blocks (one warm, one cool), one deep ink colour doing all the work (text, hairlines, buttons, the dark card), generous whitespace. Confident but unhurried; friendly, not precious. Closer to a well-designed independent studio than to a SaaS template.

**How a page is built:** a stack of full-width bands and rounded colour blocks with hairline lists in between. Every page opens on the warm band that the header sits inside (`PageIntro`), and every page closes on the ink card (the footer). Big type carries the hierarchy. There are no eyebrow labels, no ribbons, no icons-as-decoration, no gradients, no drop shadows, no glassmorphism, no stock photos.

- **Palettes:** four named palettes (Meadow, Orchard, Shore, Clay), each five brand colours in `src/routes/layout.css`: `--paper`, `--block-a` (warm tint), `--block-b` (cool tint), `--ink`, `--ink-soft`. Meadow is the default (cream `#FAFAF2`, butter `#E8EBB2`, lilac `#DCD3E8`, green `#164E3E`, `#3F5A50`). The palette is `data-theme` on `<html>`, set by mode-watcher's `setTheme`; light/dark is the `dark` class, light by default. Semantic tokens: `background`/`foreground` = paper/ink, `primary` = ink with the warm tint as its foreground, `secondary` = warm tint, `accent` = cool tint, `muted` = deeper paper, `muted-foreground` = soft ink, `border`/`input`/`ring` = ink (hairlines are full ink), `overlay` for scrims. Dark mode inverts the roles: ink page, warm tint as primary, mid-ink secondary, deep cool tint as accent. Every colour is defined for both modes in every palette. Always use the semantic tokens in components; `bg-paper`, `bg-block-a`, `bg-block-b`, `bg-ink` exist only for swatches. Never hardcode a hex outside `layout.css`. No `dark:` overrides in components; the tokens handle it.
- **Type:** Manrope 800 for headings and 700 for buttons (`font-display`), DM Sans for body (`font-sans`). Utilities in `layout.css`: `.display-1` (hero), `.display-2` (section titles), `.display-3` (card and component titles), `.display-4` (small titles), `.row-title`, `.lead`, `.figure` (big numbers), `.text-link`. Sentence case everywhere. Tight tracking only on display sizes. Numbers in tables use `tabular-nums`.
- **Rhythm:** 20px gutters on phones, 64px from `md`, 1440px max (`wrap`). Section gaps 64px / 112px (`section-gap`). Radii: 28px on colour blocks (`rounded-block`, 24px on phones), 20px on cards (`rounded-lg`), 12px (`rounded-md`) and 8px (`rounded-sm`) on small controls, 999px pills on buttons, inputs and badges. Lists use 1px ink hairlines (`border-t`/`border-b`), not cards. Control heights: 40px `sm`, 48px default, 56px `lg`.
- **Hairlines:** a 1px line is either the `border` token (on paper, where the colour is known) or `border-hairline` / `divide-hairline` (in the current text colour, for components that sit on any surface: inputs, cards, items, calendars). Both are full strength in light mode and 45% in dark (`--hairline`). `border-current` is only for the 2px outlines on buttons, toggles and switches, which stay full strength.
- **Surfaces:** paper, warm block, cool block, ink card. Components must work on all four: use `currentColor` (`border-current`, `bg-current/10`, `text-current/75`) for outline, ghost, hover and secondary-text treatments on transparent components, so they invert on the ink card where `bg-muted` and `text-muted-foreground` would vanish. A pressed or selected state that is `bg-primary` on paper swaps to `bg-primary-foreground text-primary` inside a `.bg-primary` surface (`[.bg-primary_&]:` in Tailwind). Floating layers (popover, menu, dialog, sheet) are paper with a 1px ink hairline and no shadow; the dialog scrim is `bg-overlay`.
- **Motion:** 150ms for routine state changes, 200-300ms for overlays, ease-out in and ease-in out. Hover is a tint or opacity change, never a lift. No looping decoration, no count-ups, no scroll-triggered entrances. Name the transitioned properties; never `transition-all`. Honour `prefers-reduced-motion` (the base layer already shortens all animation).
- **Icons:** Lucide only, functional only (a close, a chevron, a check). Never an icon as a bullet or a heading ornament.
- **Copy and demo content:** plain sentences, concrete verbs, no filler ("seamless", "powerful", "elevate"). No em-dashes. Buttons say what they do. Demo data is one consistent fictional world, Hollin Nursery, defined once in `src/lib/demos/world.ts`: today's date (Thursday, October 22, 2026), the shop, staff, customers, plants with prices and stock, delivery rules, the order ledger with totals computed from the lines, sales series, the status and stock badge maps, keyboard shortcuts and the US-locale formatters. Every page imports its facts from there; never retype a price, date or order number, and never invent a second version of an existing fact (add it to the module instead). Never John Doe, Acme, lorem ipsum, "example@example.com", or round "10K+" figures. Show empty, loading and error states where a component has them.
- **Favicon:** `src/lib/assets/favicon.svg` is the grass mark from `wordmark.svelte` in Meadow's ink and butter; its two hex values are the one exception to the no-hex rule outside `layout.css`.
- **Showcase pages:** a group page is `CatalogPage` with one `Section` per component (id = kebab-case component name) and one or more `Demo` blocks per section, labelled by what they show ("Sizes", "On the ink card"). Use the `tone` prop to show a component on the colour blocks and the ink card when it would be used there.
- Make every page responsive and check both modes and all four palettes.
